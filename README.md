# Dessert Shopping Cart

A small vanilla JavaScript shopping cart app for browsing dessert products, adding items to the cart, and seeing the subtotal, taxes, and total update live.

## Features

- Browse a list of desserts with prices and categories
- Add items to the cart from the product cards
- View the current cart contents
- Calculate subtotal, tax, and total in real time
- Clear the cart with confirmation
- Responsive single-page layout built with HTML, CSS, and JavaScript

## Project Structure

- `index.html` — app layout
- `styles.css` — styling
- `script.js` — product data and cart logic

## Notes

This is a front-end project with no backend or database. It is designed as a simple static web app for learning DOM manipulation and shopping cart logic in JavaScript.
